Design System · v1

RunRoute 디자인 시스템

실제 구현(src/styles/tokens.css, 각 *.module.css)의 CSS 변수 토큰과 컴포넌트 구현을 기준으로 한 일람표입니다. 문서상 규칙이 아닌 현재 코드의 토큰을 기준으로 합니다.

디자인 원칙

4가지 핵심 원칙이 모든 화면 결정의 기준입니다.

Desktop 중심 Responsive

1200px 콘텐츠 폭 기준. 767px 이하에서 단일 컬럼 / 하단 시트 모달로 전환.

토큰 재사용

색·타이포·간격·반경·그림자를 전역 CSS 변수(:root)로 정의하고 참조.

정보 우선

안전성·노면·편의시설·분위기 정보를 카드/섹션으로 명확히 노출.

재디자인 금지

확정된 UI 구조를 바꾸지 않습니다.

  • Home .grid: 3 → 2(≤1199) → 1(≤767)

Home · Detail · Saved · Login 모달 구조

Home

인트로(위치·헤딩) → 오늘의 추천(Featured) → 다른 추천(필터 Chip + 3/2/1열 그리드) → MockDataNotice

Detail

Hero(이름·요약·특성 태그, Metric) + 캐러셀 + 길찾기/저장 → 정보 Grid(안전·노면·편의·분위기) → MockDataNotice

Saved

제목 + 저장 수 → 3/2/1열 카드 그리드(빈 경우 EmptyState) → Toast

Login

전역 모달(별도 페이지 아님): 백드롭 + 이메일/비밀번호 폼 + 데모 로그인 안내

확정된 제품 UI 결정

이 결정들은 재디자인 대상이 아닙니다.

✓
서비스명은 RunRoute

RUNWAY로 되돌리지 않습니다.

✓
분위기 카드 유지

현재 텍스트 중심이나, 향후 사진이 추가될 수 있는 독립 카드 구조를 보존합니다.

✓
Saved 카드 Grid 유지

Saved는 카드형 Grid(3→2→1열)를 유지하며 1-column horizontal list로 되돌리지 않습니다.

접근성 · 키보드

Focus / Keyboard

Modal 포커스 트랩, ESC/오버레이 닫기, 열림 시 내부 포커스 이동·닫힘 후 이전 포커스 복원. SaveControl/Chip/로그인·로그아웃은 aria-pressed / 명확한 aria-label.

Live Regions

Toast role="status" / aria-live="polite". 오류 role="alert", 보조 텍스트 aria-label 제공. ImageWithFallback은 alt 누락 방지.
