Sprint 6 Design System

UIJEONGBU Running Course Web MVP Draft v0.2 2026-08-15 기준

1. Design Principles

  • Desktop-first, Mobile-safe: 데스크톱 공간을 적극 활용하되 768px 미만에서도 핵심 흐름이 깨지지 않는다.
  • Image-first Discovery: 코스 사진과 경로 이미지가 탐색 경험의 첫 번째 시각 정보가 된다.
  • Fast Judgment: 거리·시간·난이도·안전성·노면·편의시설·분위기를 짧은 카드와 태그로 빠르게 읽게 한다.
  • Clear Action: Primary Blue는 저장·길찾기·주요 CTA 등 핵심 행동에 우선 사용한다.
  • Soft & Clean: 밝은 배경, 큰 Radius, 얇은 Border, 약한 Shadow로 기존 앱의 가벼운 인상을 유지한다.
  • Platform-independent Core: Color·Typography·Spacing·Radius의 의미는 향후 React Native + Expo에서도 재사용 가능해야 한다.

11. Web ↔ Future App Reuse Rule

  • 토큰 이름: color.primary.500, space.16, radius.lg — 플랫폼 독립적 의미 유지
  • Web: CSS Variables로 매핑 (예: --color-primary-500)
  • React Native: 동일 의미의 TypeScript theme object로 매핑 가능
  • Web-only rule: hover, breakpoint, Desktop Grid, Top Navigation은 분리
  • 금지: 코스 데이터에 CSS class, JSX, DOM 정보 또는 Web 전용 asset import

12. Do / Don't

✅ Do

  • 기존 앱의 Blue/Lime, 이미지 중심 카드, 부드러운 Radius, 짧은 정보 카드를 유지한다.
  • Desktop에서 넓은 공간을 Grid와 2열 구조로 활용한다.
  • 저장과 길찾기의 우선순위를 명확하게 보여준다.
  • PRD에 정의된 MVP 기능만 UI에 노출한다.

❌ Don't

  • 모바일 앱 화면을 그대로 430px 폭으로 중앙에 배치하지 않는다.
  • 검색, 운동, 프로필, 평점 등 Out of Scope 기능을 시안에 있다는 이유만으로 추가하지 않는다.
  • Accent Lime를 긴 본문이나 저대비 텍스트에 사용하지 않는다.
  • 카드마다 서로 다른 Radius, Shadow, Button 규칙을 임의로 만들지 않는다.
